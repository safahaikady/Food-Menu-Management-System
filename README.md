🍔🍕 Food Menu Management System 🍟🥤
✨ A simple and interactive Food Menu Management System developed using HTML, CSS, and JavaScript. This project allows users to easily view food items 🍽️, add items to the cart 🛒, remove unwanted items ❌, and generate bills 🧾 in a smooth and user-friendly interface 💻. The system also includes an admin panel 👨‍💼 that enables administrators to dynamically manage the menu by adding new food items ➕, deleting items 🗑️, and updating prices 💰. This project demonstrates the use of front-end web technologies along with local storage for managing data efficiently 🚀.
